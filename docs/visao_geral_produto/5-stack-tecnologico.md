# Stack Tecnológico

## Frontend

- **React**
- **Next.js**
- **Tailwind CSS**

**Hospedagem:** Vercel

O frontend da aplicação será desenvolvido utilizando **React com Next.js**, permitindo a construção de uma interface web moderna, performática e escalável.

O **Tailwind CSS** será utilizado para estilização da interface, permitindo a criação de layouts responsivos e padronizados por meio de classes utilitárias.

A aplicação será hospedada na plataforma **Vercel**, que oferece integração nativa com projetos Next.js, facilitando o processo de deploy, atualização contínua e escalabilidade da aplicação.

---

## Backend

- **JavaScript**
- **Next.js**

**Hospedagem:** Vercel

O backend da aplicação será desenvolvido utilizando **JavaScript com Next.js**, aproveitando os recursos de **API Routes** para criação das rotas responsáveis pela comunicação entre o frontend e o banco de dados.

Essa abordagem permite manter **frontend e backend dentro do mesmo projeto**, simplificando a organização da aplicação e o processo de deploy.

---

## Banco de Dados

- **PostgreSQL**

**Hospedagem:** Supabase

O banco de dados utilizado será o **PostgreSQL**, um sistema gerenciador de banco de dados relacional amplamente utilizado por sua **robustez, confiabilidade e suporte a transações**.

O banco será hospedado na plataforma **Supabase**, que oferece infraestrutura gerenciada para PostgreSQL, além de ferramentas que facilitam o gerenciamento do banco de dados durante o desenvolvimento.

---

## API Consumida

- **ViaCEP**

A aplicação consumirá a **API ViaCEP**, que será utilizada para **buscar automaticamente informações de endereço a partir do CEP informado**.

Essa integração permitirá que formulários de cadastro que exigem endereço sejam preenchidos de forma mais rápida e padronizada.

---

## ORM de Acesso ao Banco

- **Prisma**

O acesso ao banco de dados será realizado utilizando o **Prisma**, um ORM que facilita a comunicação entre a aplicação e o banco de dados PostgreSQL.

O Prisma permite:

- modelagem estruturada do banco de dados;
- geração automática de consultas;
- maior segurança na manipulação de dados;
- organização e padronização das operações de banco.

---

## Arquitetura

- **Arquitetura em Camadas**

A aplicação será estruturada utilizando **arquitetura em camadas**, separando responsabilidades dentro do sistema.

Essa abordagem facilita:

- organização do código
- manutenção da aplicação
- escalabilidade do projeto
- separação clara entre responsabilidades do sistema

---

## Versionamento

- **GitHub**

O controle de versão do projeto será realizado utilizando **GitHub**, permitindo:

- controle de histórico de alterações no código;
- gerenciamento de versões do sistema;
- organização do fluxo de desenvolvimento.

---

## IDE

- **Visual Studio Code (VS Code)**

O desenvolvimento da aplicação será realizado utilizando a IDE **Visual Studio Code**, que oferece suporte completo ao desenvolvimento em JavaScript, React e Next.js.

### Extensões utilizadas na IDE

- **Tailwind CSS**
- **Prisma**
- **ESLint**
- **ES7+ React/Redux/React-Native Snippets**

Essas extensões auxiliam no desenvolvimento ao fornecer:

- suporte à escrita de código;
- padronização de boas práticas;
- aumento da produtividade durante a implementação do sistema.
